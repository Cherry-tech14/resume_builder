# Resume Builder

A beginner-friendly Resume Builder application built with Python.

The goal of this project is to create a simple and flexible application that allows users to provide their professional information and build a well-structured resume.

## Current Features

The application currently collects:

* Personal information
* Professional summary
* Education history
* Work experience
* Skills
* Certifications

The application supports multiple entries for sections such as education, work experience, skills, and certifications.
